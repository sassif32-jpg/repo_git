# Creare una repository su GitHub
 Dal progetto locale al progetto condiviso

 ## Installazione Repository da terminale

0. apertura terminale
1. clonare la repository `git clone https://github.com/sassif32-jpg/repo_git.git`
2. entrare nella cartella `cd REPO_GIT`


 ## Apertura della pagina Web da Terminale

 0. aprire il terminale e entrare nella cartella dove ho scaricato il progetto
 1. `cd REPO_GIT`
 2. `cd src`
